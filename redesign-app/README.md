# redesign-app

پوشهٔ فایل‌های بازطراحی اپلیکیشن «سیلانه‌سبز لرنینگ».

فایل‌های مرجع (طراحی، دارایی‌های گرافیکی، متن‌ها، نمونه‌ها) را اینجا بگذارید تا در فازهای بازطراحی استفاده شوند.

دیزاین‌سیستم پیشنهادی در PR #39 در مسیر `docs/design-system/` قرار دارد.

## پیشنهاد ساختار

- `assets/` تصاویر و کاراکترها
- `references/` فایل‌های مرجع و اسکرین‌شات‌ها
- `copy/` متن‌ها و لحن

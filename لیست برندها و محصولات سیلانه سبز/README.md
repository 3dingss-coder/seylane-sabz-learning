# خروجی برندها و محصولات (Silaneh Sabz Plus)

داده‌ها مستقیماً از مایگریشن‌های `worker/migrations/*.sql` استخراج شده‌اند (همان منبعی که
دیتابیس D1 واقعی را می‌سازد)؛ بنابراین همه‌ی تغییراتِ حذف برند، ادغام برند، دسته‌بندی
شش‌گانه و مخفی‌سازی محصولات بدون تصویر در خروجی اعمال شده است.

## فایل‌ها

| فایل | توضیح |
| --- | --- |
| `silaneh-sabz-plus-brands-products.xlsx` | فایل اصلی با ۴ شیت — برای آپلود مستقیم در Google Sheets |
| `brands.csv` | خلاصه‌ی برندها |
| `products.csv` | فهرست کامل محصولات فعال |
| `brand-category-matrix.csv` | جدول تقاطعی برند × دسته‌بندی |
| `hidden-products.csv` | محصولات غیرفعال + دلیل عدم نمایش |

## نحوه‌ی import در Google Sheets

1. در Google Drive روی **New ▸ File upload** بزنید و فایل
   `silaneh-sabz-plus-brands-products.xlsx` را انتخاب کنید.
2. روی فایل آپلودشده راست‌کلیک ▸ **Open with ▸ Google Sheets**.
   (یا از داخل Sheets: **File ▸ Import ▸ Upload**.)

اگر فقط CSV می‌خواهید: **File ▸ Import ▸ Upload ▸ Separator: Comma** — فایل‌ها با
`UTF-8 BOM` ذخیره شده‌اند تا فارسی درست نمایش داده شود.

## شیت‌های فایل اکسل

1. **برندها** — نام فارسی/لاتین برند، شناسه، تعداد محصولات فعال، دسته‌بندی‌ها،
   کمینه/بیشینه/میانگین قیمت عمده.
2. **محصولات** — ۲۳۸ محصول فعال کاتالوگ با برند، کد، بارکد، نام، دسته‌بندی،
   تعداد در کارتن، قیمت عمده هر عدد، قیمت کارتن، قیمت مصوب مصرف‌کننده،
   درصد سود فروشگاه، لینک تصویر، توضیحات و شناسه محصول.
3. **برند × دسته‌بندی** — تعداد محصول هر برند در هر یک از ۶ دسته‌بندی.
4. **محصولات غیرفعال** — ۴۲ محصولی که در اپلیکیشن نمایش داده نمی‌شوند، همراه با دلیل
   (بدون تصویر / برند حذف‌شده / محصول دموی قدیمی).

## چند نکته‌ی داده‌ای

- `price` = **قیمت عمده‌ی هر عدد** (مبلغی که مشتری عمده می‌پردازد)،
  `unit_price` = **قیمت مصوب مصرف‌کننده** (همان‌طور که در `src/components/ProductModal.tsx` نمایش داده می‌شود).
- ستون «سود فروشگاه» برابر است با `(قیمت مصرف‌کننده − قیمت عمده) ÷ قیمت مصرف‌کننده × ۱۰۰`.
- `carton_quantity` برای **تمام** محصولاتِ کاتالوگ واقعی برابر `۱` است
  (فقط محصولات دموی قدیمی مقادیر ۱۲/۲۴/۳۶/۴۸ داشتند) — یعنی این فیلد هنوز برای
  کاتالوگ واقعی پر نشده است.
- هیچ محصول فعالی تخفیف (`discount_percentage`) یا وضعیت «پیشنهاد ویژه» ندارد؛
  همه موجود (`in_stock = 1`) هستند.

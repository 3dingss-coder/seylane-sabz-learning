## ۴.۱ `Button` — واریانت `cta`

```tsx
// apps/web/src/components/ui/Button.tsx — فقط اپ بازاریاب (از prop context یا className)
cta: 'bg-energy text-white rounded-card [box-shadow:var(--lip-md)] ' +
     'active:translate-y-1 active:[box-shadow:none] ' +          // «فشار» واقعی
     'disabled:bg-swan disabled:text-muted disabled:[box-shadow:none]', // لبه حذف = غیرفعال
```

| قاعده | |
|---|---|
| B-01 | `cta` فقط با `size="lg"` (متن ≥۱۸px Bold → کنتراست ۳٫۱۸:۱ مجاز) |
| B-02 | در هر صفحه حداکثر **یک** `cta`. بقیه `secondary/ghost` |
| B-03 | `:active` با `transform` — هرگز `margin/height` (M-01) |
| B-04 | `aria-pressed` برای دکمه‌های toggle ایستگاه |

**کجا:** دکمهٔ «شروع/ادامه» در کارت hero (M3) و دکمهٔ «ثبت پاسخ» در دوئل (M7). همین دو.

## ۴.۲ `Card` — prop `chunky`

```tsx
chunky && 'border-2 border-chunk'   // ۲px = عمق فیزیکی، ارزان‌تر از سایه
```

- فقط اپ بازاریاب. پنل‌ها همان `border` + `shadow-sm`.
- `tone="hero"` موجود + لبهٔ `--lip-lg` زیر کارت = «قهرمان صفحه».

## ۴.۳ `CountdownChip` — سه سطح هشدار

| سطح | شرط | سبک |
|---|---|---|
| آرام | > 48h | `bg-surface border text-ink-2` |
| هوشیار | 24–48h | `bg-warning-light text-warning-fg` (۴٫۵۱:۱ ✅) |
| فوری | < 24h | `bg-streak text-streak-fg` + `animate-pulse-dot` یک‌باره |

`aria-live="polite"` + برچسب کامل فارسی («دو روز تا پایان مهلت») — نه فقط عدد. (spec §16.8 همین را می‌خواهد؛ اینجا بصری هم می‌شود.)

## ۴.۴ `EmptyState` + کاراکتر

```tsx
<EmptyState
  character={{ id: 'seyla', expression: 'nudge' }}
  title="هنوز آموزشی ندارید"
  description="سیلا منتظرته؛ به محض فعال‌شدن اولین بسته، همین‌جا می‌بینی."
  action={<Button variant="secondary">به کارت‌های من برو</Button>}
/>
```

- قاعدهٔ E-01: هر EmptyState **یک CTA** دارد. صفحهٔ بن‌بست ممنوع.
- قاعدهٔ E-02: لحن Empty هرگز تنبیهی نیست. «تو دیر کردی» ممنوع.

## ۴.۵ `PathScreen` — بزرگ‌ترین قطعهٔ جدید (جایگزین بصری M5)

```
┌───────────────────────────────┐
│  مسیر: مراقبت پوست — برندهای جدید        │
│  [سپر: ۲]  [پیوستگی: 🔥۱۴]  [سکه: ۲۴۰]   │ ← نوار وضعیت بالا (chips)
│                               │
│        ( ایستگاه ۱ ✔ )         │
│           │                   │
│       ( ایستگاه ۲ ✔ )          │   موج‌دار، یک در میان چپ/راست
│           │                   │
│      ● ایستگاه ۳ — نوبت تو ●    │   پرِ #21A55F + لبه + pulse یک‌باره
│           │                   │
│       ( دوئل با سیمین 🔒 )       │
│           │                   │
│       ( ایستگاه ۵  )          │
───────────────────────────────
```

- کاشی‌ها `--radius-station` (۲۴px)، دایره‌ای، ۷۲px.
- **فقط یک** `cta` زیر ایستگاهٔ فعلی: «ادامه ایستگاه ۳».
- کلیک روی قفل → `Tooltip` با `role="status"`: «اول ایستگاه قبلی».
- RTL: موج از راست شروع می‌شود؛ آیکون‌های جهت‌دار با `.rtl-mirror`.
- در ≥1024px مسیر به **ستون وسط** می‌آید و دو ستون کناری (پیشرفت / مرورهای امروز) چسبان می‌شوند.

## ۴.۶ `DuelScreen` — آزمون به‌شکل دوئل (جایگزین بصری M7)

```
┌───────────────────────────────┐
│  [سیمین]  🤨   «خب، اینو که همه می‌گن…»  │ ← حباب گفتار سیمین = متن سؤال
│  نوار اعتماد: ███████░░░ ۶۰٪           │ ← TrustBar (سبز → نارنجی)
│  ─────────────────────────────        │
│  گزینه‌های بزرگ (Radio، ۴۸px)          │
│  ─────────────────────────────        │
│  نوار بازخورد چسبان پایین:            │
│   درست → #DFF5E9 + متن #115E3D + سیمین impressed
│   غلط  → #FFDFE0 + متن #A81F1F + «پاسخ درست: …» بدون سرزنش
└───────────────────────────────┘
```

| قاعده | |
|---|---|
| D-01 | نوار بازخورد **پایین صفحه چسبان** است (نه مدال) — همان الگوی دولینگو |
| D-02 | پاسخ غلط چهرهٔ سیمین را به `thinking` می‌برد، نه `angry` — و هرگز `celebrate` برای غلط |
| D-03 | امتیاز دوئل با CountUp شمرده می‌شود (M-03) |
| D-04 | مرور پاسخ‌ها (که الان هست) با آیکون‌های `pop/shake` موجود — همان که `QuizPage` دارد |
| D-05 | دکمهٔ ادامهٔ نوار بازخورد **یک رنگ**: درست=سبز، غلط=قرمز — همان دولینگو |

`TrustBar`:
```tsx
// رنگ بر اساس مقدار: <40 #FF9600 · 40–70 #FFC800 · >70 #21A55F — با برچسب متنی همیشه
<div role="progressbar" aria-valuenow={trust} aria-label="اعتماد مشتری">…</div>
```

# دیزاین‌سیستم «سیلانه‌سبز لرنینگ» — مهندسی معکوس از دولینگو

> **خلاصهٔ یک‌خطی:** ما دیزاین‌سیستم دولینگو را **تا ریزترین نکته** کالبدشکافی کردیم (فاز ۰) و سپس آن را — نه با کپی رنگ و ماسکوت — بلکه با **بازمهندسی ساختار و مکانیک** برای یک اپ توانمندسازی بازاریاب‌های سیلانه‌سبز بازطراحی کردیم، در ۸ فاز اجرایی.
>
> **پیش‌نمایش زندهٔ سیستم:** `preview/index.html` را باز کنید (یا `npx serve preview`).

---

## چرا این پروژه «تعویض رنگ» نیست؟

دولینگو برای **یادگیرندهٔ زبان** طراحی شده؛ ما برای **بازاریاب محصول** که باید **فهم عمیق** و **قدرت متقاعدسازی** پیدا کند. پس:

| از دولینگو گرفتیم | برای سیلانه بازطراحی شد به |
|---|---|
| Duo (جغد) | **سیلا** — مسکات رسمی برند (پرندهٔ بنفش با تاج قرمز، `مسکات.png`) |
| The Path | **مسیر برند** (ایستگاه = قسمت) |
| آزمون | **دوئل با سیمین** — مشتری مردد با نوار اعتماد |
| Hearts/Energy | **حذف شد** — تنبیه، توانمندسازی نیست |
| Gems/فروشگاه مجازی | **سکهٔ توانمندی → پاداش واقعی** |
| Leagues | **لیگ تیمی opt-in** که مدیر نمی‌بیند |
| `#58CC02` با کنتراست ۲٫۰۹:۱ | خانهٔ سبز/سفید `#177A50` (۵٫۳۴:۱) + سبز روشن پویا؛ بنفش **فقط** مسکات (۶٫۶۸:۱) |
